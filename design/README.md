# Módulo de Diseño y Prototipado (UI/UX) — PC Doctor

Este directorio contiene la documentación visual, diagramas de flujo y esquemas de interfaz para la aplicación PC Doctor[cite: 1].

## Arquitectura de Interfaces

La solución se compone de tres vistas principales diseñadas para el flujo de diagnóstico[cite: 1]:

1. **Pantalla 1 — Inicio:**
   * Módulo principal: Acceso al cuestionario asistido por el motor de reglas determinista[cite: 1].
   * Módulo secundario: Entrada de texto libre para procesamiento sintomático mediante Lenguaje Natural (NLP/IA)[cite: 1].

2. **Pantalla 2 — Cuestionario Interactivo:**
   * Indicador de progreso del flujo de evaluación[cite: 1].
   * Despliegue de preguntas y opciones de selección simple para el usuario[cite: 1].

3. **Pantalla 3 — Diagnóstico y Soluciones:**
   * Visualización de probables causas calculadas por el motor de reglas expresadas en porcentaje de probabilidad[cite: 1].
   * Lista detallada de recomendaciones y pasos de resolución técnica[cite: 1].
